HPU Interface Control Document (synthetic demo data)

1 Interfaces

The HPU receives commands from the CDU and reports status to the FMU LRM over the avionics bus. In the system integration test bench the CDU simulator sends the commands, the HYD simulator drives the pressure switch input and the HPU outputs are inspected on the HPU LRM RX channel.
